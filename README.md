# HandDJ

HandDJ is a gesture-controlled DJ application that lets you manipulate music in real time using just your hands. It combines computer vision-based hand tracking with live audio processing, plus a physical Arduino-driven interface for selecting tracks.

## How It Works

- **Hand tracking** is done using [MediaPipe](https://developers.google.com/mediapipe) hand detection, which tracks the position of your fingers and hands via webcam.
- **Audio playback and effects** are handled through [JUCE](https://juce.com/) (via Projucer), which processes the live audio stream.
- Gestures map to audio parameters as follows:
  - **Distance between fingers** → controls **volume**
  - **Distance between hands** → controls **playback speed** and **frequency/pitch**
- **Track selection** is handled externally via an **Arduino-connected LCD screen**. The Arduino sends the selected track back to the application over a **serial port** connection.

## Features

- Real-time hand-gesture control of volume, speed, and frequency
- Webcam-based tracking, no specialized hardware required for gesture input
- Physical track selection via Arduino + LCD display
- Serial communication between Arduino and the JUCE application

## Hardware Requirements

- A webcam (built-in or external)
- An Arduino board wired to an LCD display
- A serial connection (e.g., USB) between the Arduino and your computer

## Software Requirements

- [JUCE](https://juce.com/) framework
- [Projucer](https://juce.com/discover/projucer) (used to generate/manage the Xcode project)
- Xcode (for building on macOS)
- Python with [MediaPipe](https://pypi.org/project/mediapipe/) installed (for hand detection)
- Arduino IDE (for flashing the Arduino sketch, if modifying track-selection hardware)

## Building the Project

1. Open `HandDJ.jucer` in **Projucer**.
2. Use Projucer to export/update the Xcode project (this regenerates files inside `Builds/MacOSX`).
3. Open the generated Xcode project at `Builds/MacOSX/HandDJ.xcodeproj`.
4. Build and run from Xcode.
5. Connect your Arduino (with the LCD sketch flashed) via USB before launching, so the serial connection is available on startup.
6. Run the Python/MediaPipe hand-tracking script (in `pythonhand/`) alongside the app to enable gesture control.

## Usage

1. Power on and connect the Arduino; select a track using the LCD interface.
2. Launch the HandDJ application.
3. Start the hand-tracking script so your webcam feed is being processed.
4. Use hand gestures to control playback:
   - Move fingers apart/together to adjust **volume**
   - Move hands apart/together to adjust **speed** and **frequency**

## Notes

- This project was built using JUCE + Projucer for audio handling, so any changes to audio modules or build targets should be made through Projucer and re-exported, not edited directly in the Xcode project files.
